## 目录📖

### 1 用户系统  ✨
#### 1.1 注册与认证   
&emsp;&emsp;•	多方式注册：支持手机号、邮箱、第三方账号（微信/微博）注册  
&emsp;&emsp;•	分级认证体系:  
&emsp;&emsp;&emsp;&emsp;◦	基础认证：手机/邮箱验证    
&emsp;&emsp;&emsp;&emsp;◦	实名认证：身份证+人脸识别（可选）  
&emsp;&emsp;&emsp;&emsp;◦	专业认证：上传从业资格、学历证明等（加V标识）  
&emsp;&emsp;&emsp;&emsp;◦	投资者适当性评估：专业用户需完成风险评估问卷  
#### 1.2 个人资料管理  
&emsp;&emsp;•	基本信息：昵称、头像、个人简介、投资经验标签  
&emsp;&emsp;•	投资偏好：关注领域（A股/港股/美股/基金等）、风险偏好  
&emsp;&emsp;•	成就系统：发帖数、精华帖、影响力值、荣誉勋章  
&emsp;&emsp;•	隐私设置：控制信息可见范围

&emsp;&emsp;&emsp;&emsp;◦	宏观策略研讨

&emsp;&emsp;•	问答求助区：新手提问、投资解惑

&emsp;&emsp;&emsp;&emsp;◦	多级评论系统（支持楼中楼）  
&emsp;&emsp;&emsp;&emsp;◦	@提及功能

&emsp;&emsp;•	附件支持：上传PDF、Excel等分析报告（需审核）
