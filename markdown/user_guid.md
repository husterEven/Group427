## 一、快速入门

### 1.1 注册账号

1. 打开浏览器，访问 `http://localhost:3000/register`
2. 填写注册信息：
   - **手机号**或**邮箱**（二选一，用于登录）
   - **昵称**：2-20 个字符，将显示在帖子、评论旁
   - **密码**：6-32 位
   - **性别**：可选
3. 点击 **"注册"** 按钮
4. 注册成功后自动登录，跳转至首页

### 1.2 登录

1. 访问 `http://localhost:3000/login`
2. 输入注册时使用的手机号/邮箱和密码
3. 点击 **"登录"** 按钮

> 登录有效期：Access Token 2 小时，Refresh Token 7 天。如遇 401，重新登录即可。

### 1.3 页面布局

登录后，页面分为三部分：

```
┌──────────────────────────────────────────────┐
│ 头部导航栏                                    │
│ [Logo] [搜索框] [动态] [通知] [私信] [群组] [发帖] [头像] │
├────────┬─────────────────────────────────────┤
│ 左侧   │                                     │
│ 板块   │         内容区域                      │
│ 导航   │                                     │
│        │                                     │
├────────┴─────────────────────────────────────┤
```

| 区域 | 说明 |
|------|------|
| 头部导航栏 | Logo、搜索框、功能入口图标、发帖按钮、用户头像菜单 |
| 左侧导航 | 投资板块分类，点击展开子板块 |
| 内容区域 | 当前页面的主体内容 |

**头部功能图标：**

| 图标 | 功能 | 路径 |
|------|------|------|
| 🏠 首页 | 实时动态流 | `/dynamics` |
| 🔔 铃铛 | 消息通知（有未读时显示红点） | `/notifications` |
| 💬 消息 | 私信会话列表（有未读时显示红点） | `/messages` |
| 👥 群组 | 我的群组列表 | `/groups` |
| **[+发帖]** | 发布新帖子 | `/editor` |
| 头像 | 个人中心菜单 | — |

## 二、首页浏览

### 2.1 帖子列表

首页显示全站帖子列表，支持以下操作：

**排序切换：**

| 排序方式 | 说明 |
|---------|------|
| 最新 | 按发布时间倒序（默认） |
| 最热 | 按点赞+评论数排序 |
| 最受欢迎 | 按点赞数排序 |

**板块筛选：** 点击左侧导航中的板块/分区，只显示该板块的帖子。

**搜索功能：** 在顶部搜索框输入关键词，按回车搜索帖子标题和正文内容。

### 2.2 帖子卡片

每个帖子显示：
- 作者头像、昵称、等级
- 帖子标题（点击进入详情）
- 内容摘要
- 板块标签
- 互动数据：浏览量、点赞数、评论数、收藏数
- 发布时间

## 三、发帖互动

### 3.1 发布帖子

点击右上角 **"[+发帖]"** 按钮，进入帖子编辑器。

**三种帖子类型：**

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| **普通发帖** | 10 行文本框，适合短内容 | 日常讨论、行情速递 |
| **长文分析** | 20 行文本框，适合深度分析 | 策略研究、公司分析 |
| **投票调研** | 设置标题 + 2~10 个选项 + 截止时间 | 市场观点调查 |

填写内容后，选择**板块**和**分区**，点击 **"发布"**。

### 3.2 帖子操作

进入帖子详情页（点击帖子标题），可进行以下操作：

| 操作 | 按钮 | 说明 |
|------|------|------|
| **点赞** | :+1: | 点击点赞，再次点击取消。红色表示已点赞 |
| **收藏** | :star: | 点击收藏，再次点击取消。可在个人中心查看收藏列表 |
| **评论** | 底部评论框 | 输入内容后点击发送 |
| **分享** | — | 复制帖子链接分享给他人 |

**作者本人**可编辑或删除自己的帖子。

## 四、评论与投票

### 4.1 发表评论

在帖子详情页底部输入评论内容，点击 **"发表评论"**。

### 4.2 楼中楼回复

点击某条评论下的 **"回复"** 按钮，可针对该评论进行回复，形成嵌套讨论。

| 排序方式 | 说明 |
|---------|------|
| 按时间 | 最早显示在前面 |
| 按热度 | 被点赞多的评论优先 |

### 4.3 投票功能

在投票帖中：

1. **选择**其中一个选项
2. 点击 **"投票"** 提交
3. 投票截止前：显示各选项票数
4. 投票截止后：显示柱状图与百分比结果
5. 每人仅可投票一次，不可更改

### 4.4 创建投票

在发帖时选择**投票调研**模式：

1. 输入投票标题（如："你看好下半年哪个板块？"）
2. 添加选项（最少 2 个，最多 10 个）
3. 设置截止时间
4. 选择板块后发布

## 五、个人中心

点击右上角**头像** → **"个人主页"**，或访问 `/profile/:userId`。

### 5.1 个人主页

展示以下信息：
- 头像、昵称、个人简介
- 等级、积分、认证标识
- 关注数、粉丝数
- 用户发布的帖子列表

> 访问自己的主页显示 **[编辑资料]** 按钮，访问他人主页显示 **[关注]** **[发私信]** 按钮。

### 5.2 账号设置

点击头像菜单中的 **"账号设置"**，进入设置中心：

| 页面 | 路径 | 功能 |
|------|------|------|
| **编辑资料** | `/settings/profile` | 修改头像、昵称、个人简介、性别 |
| **修改密码** | 编辑资料页内 | 提供旧密码和新密码 |
| **投资偏好** | `/settings/preference` | 设置关注市场、风险偏好类型 |
| **隐私设置** | `/settings/privacy` | 设置个人主页可见性范围 |
| **认证中心** | `/settings/verification` | 提交实名认证申请，查看认证状态 |
| **成就系统** | `/settings/achievement` | 查看帖子数、精华帖数等成就 |
| **风险评估** | `/settings/risk` | 完成投资风险承受能力评估问卷 |

## 六、社交功能

### 6.1 实时动态

路径：`/dynamics`

类似微博/朋友圈的短动态功能：

- **发布动态**：在输入框中输入内容（纯文本），点击发布
- **动态流**：查看所有用户的最新动态
- **我的动态**：在个人主页查看指定用户的动态列表
- 点击动态可查看详情，作者可删除自己的动态

### 6.2 关注系统

| 操作 | 位置 | 说明 |
|------|------|------|
| **关注用户** | 他人主页 → 点击 **[关注]** | 关注后可在动态流中看到 TA 的发帖 |
| **取消关注** | 他人主页 → 再次点击 **[关注]** | Toggle 模式 |
| **设为星标** | 关注列表 → 点击星标按钮 | 特别关注，优先展示 |
| **查看关注** | 头部菜单 → 关注列表 `/following` | 查看自己关注的所有用户 |
| **查看粉丝** | 头部菜单 → 粉丝列表 | 查看关注自己的所有用户 |

> 当你被关注时，会收到通知提醒。

### 6.3 私信聊天

路径：`/messages`

**发起私信：**

1. 进入对方个人主页
2. 点击 **[发私信]** 按钮
3. 进入一对一聊天界面

**聊天操作：**

| 操作 | 说明 |
|------|------|
| 发送消息 | 输入文字后按 Enter 发送（Shift+Enter 换行） |
| 查看会话 | `/messages` 显示所有会话列表，按最后消息时间排序 |
| 未读标记 | 未读消息会在私信图标上显示红点数字徽章 |

> 收到新私信时，消息通知列表和私信图标上都会有提醒。

## 七、消息通知

路径：`/notifications`

### 7.1 通知类型

| 图标 | 类型 | 触发条件 |
|------|------|---------|
| 🔔 | 系统通知 | 被拉入群组、成为/撤销群组管理员 |
| ❤️ | 点赞通知 | 你的帖子或评论被点赞 |
| 💬 | 评论通知 | 你的帖子被评论、你的评论被回复 |
| 👤 | 关注通知 | 有人关注了你 |
| ✉️ | 私信通知 | 收到新私信 |
| 🔔 | 举报结果 | 你提交的举报有处理结果 |

### 7.2 操作

- **点击通知**：标记为已读并跳转到对应内容（帖子/用户主页/群组页面）
- **已读标识**：已读通知会以半透明显示
- **全部已读**：点击 **"全部已读"** 按钮标记所有通知为已读
- **实时轮询**：未读通知数量每 30 秒自动更新

## 八、群组管理

路径：`/groups`

### 8.1 创建群组

1. 在群组列表页点击 **"创建群组"**
2. 输入群组名称
3. 选择加入模式：
   - **自由加入（0）**：任何用户可直接加入
   - **需要审核（1）**：用户申请后需管理员批准
   - **禁止加入（2）**：仅可通过邀请加入
4. 创建者自动成为**群主**（角色等级：2）

### 8.2 成员角色

| 角色 | 等级 | 权限 |
|------|------|------|
| **群主** | 2 | 所有权限：修改信息、管理成员、踢人、任命管理员 |
| **管理员** | 1 | 管理成员、踢出普通成员 |
| **普通成员** | 0 | 查看群组、发表群帖子、邀请他人 |

### 8.3 群组操作

| 操作 | 权限要求 | 说明 |
|------|---------|------|
| 查看群组详情 | 任何群成员 | 查看群信息、成员列表 |
| 修改群组信息 | 群主 | 修改名称、加入模式、状态 |
| 邀请成员 | 任何群成员 | 被邀请者直接加入，会收到通知 |
| 加入群组 | 任何用户 | 根据群组模式决定 |
| 退出群组 | 任何群成员 | 群主退出时自动转移给最早加入的成员 |
| 群内发帖 | 任何群成员 | 仅群成员可见 |
| 设置管理员 | 群主/管理员 | 提升/撤销普通成员的管理员权限 |
| 踢出成员 | 群主/管理员 | 将成员移出群组 |

### 8.4 群组通知

- 被邀请加入群组时 → 收到系统通知
- 被设为/撤销管理员时 → 收到系统通知
- 点击通知可跳转到对应群组页面

## 九、管理后台（管理员）

> **管理员要求**：认证等级 ≥ 3（`verificationLevel >= 3`），路径：`/admin/*`

### 9.1 数据大盘

路径：`/admin/dashboard`

展示全站数据概览：
- 用户总数、帖子总数、评论总数
- 各板块帖子分布
- 最近注册用户趋势

### 9.2 内容审核

路径：`/admin/audit`

| 操作 | 说明 |
|------|------|
| 查看审核队列 | 按内容类型（帖子/评论/附件）和状态筛选 |
| 通过审核 | 内容正常发布 |
| 驳回审核 | 填写驳回原因，内容隐藏 |

### 9.3 举报处理

路径：`/admin/reports`

- 查看用户提交的举报列表
- 按状态（待处理/已处理）筛选
- 处理举报时可同时下发处罚

### 9.4 处罚管理

路径：`/admin/punishments`

- 查看所有处罚记录
- 按用户搜索处罚历史
- 撤销已生效的处罚

### 9.5 用户监控

路径：`/admin/users`

- 搜索指定用户
- 查看用户行为日志
- 监控异常活动
