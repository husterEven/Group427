# 1 用户系统  
## 1.1 注册与认证  
### 多方式注册  
- 作为一名新用户，我想通过手机号注册账号，以便快速完成论坛入驻。
- 作为一名习惯邮箱登录的用户，我想通过邮箱注册账号，以便使用邮箱接收论坛通知与找回密码。
- 作为一名不想繁琐注册的用户，我想通过微信 / 微博第三方账号一键登录注册，以便免填信息快速进入论坛。  
### 分级认证体系 - 基础认证  
- 作为一名普通浏览用户，我想完成手机 / 邮箱基础验证，以便解锁发帖、评论、点赞等基础论坛权限。  
### 分级认证体系 - 实名认证  
- 作为一名想要提升账号可信度的投资者，我想提交身份证 + 人脸识别完成实名认证，以便获得真实用户标识，增强发帖可信度与账号安全。  
### 分级认证体系 - 专业认证  
- 作为一名金融从业 / 专业投资者，我想上传从业资格证、学历证明进行专业认证，以便获得官方加 V 标识，提升个人专业影响力。  
### 投资者适当性评估  
- 作为一名已专业认证的用户，我想完成风险评估问卷，以便匹配对应投资权限、参与专业投资板块讨论，符合投资者适当性规范。

## 1.2 个人资料管理  
### 基本信息  
- 作为一名论坛用户，我想自定义昵称、头像、个人简介、投资经验标签，以便打造个人投资人设，让他人快速了解我的投资背景。  
### 投资偏好  
- 作为一名有固定投资方向的用户，我想设置关注市场（A 股 / 港股 / 美股 / 基金）、个人风险偏好，以便平台为我精准推荐对应内容和板块。  
### 成就系统  
- 作为一名活跃发帖用户，我想查看发帖数、精华帖、影响力值、荣誉勋章，以便直观看到自己在论坛的成长与行业认可度。  
### 隐私设置  
- 作为一名注重隐私的用户，我想自主设置个人资料、动态、关注列表的可见范围以便保护个人投资隐私，避免信息随意公开。

# 2 内容系统  
## 2.1 板块分类  
- 作为一名跨市场投资者，我想论坛按A 股 / 港股 / 美股 / 期货划分市场讨论区，以便快速直达对应市场看帖交流。
- 作为一名价值投资爱好者，我想进入价值投资 / 量化 / 基金 / 新股新债 / 宏观策略 / 公司研究专属专区，以便精准同好交流、垂直学习。
- 作为一名投资新手，我想进入问答求助区提问，以便向大佬请教投资问题、解决新手疑惑。
- 作为一名平台运营管理员，我想动态新增、删除、修改论坛板块，以便根据市场热点和用户需求灵活调整论坛结构。  
## 2.2 发帖与互动  
### 多样化发帖  
- 作为一名普通用户，我想发布文字 + 图片 + 基础格式普通帖子，以便日常分享行情观点和投资心得。
- 作为一名深度分析用户，我想使用富文本编辑器、插入图表发布长文分析，以便专业输出个股、市场深度研报内容。
- 作为一名发起观点调研的用户，我想创建投票调研帖，以便收集市场情绪、投资观点统计。
- 作为一名盘中短线投资者，我想发布实时简短动态讨论，以便盘中即时交流行情、分享实时看法。 
### 内容交互  
- 作为一名论坛用户，我想对帖子进行点赞、收藏、转发，以便收藏优质内容、认可作者观点、分享给好友。
- 作为一名参与讨论的用户，我想使用多级楼中楼评论，以便针对楼层单独回复，开展分层讨论。
- 作为一名论坛用户，我想在帖子中@其他用户，以便提醒指定用户查看、参与讨论。
- 作为一名有私聊需求的用户，我想使用私信功能发送文字和图片以便私下和大佬、好友一对一交流投资思路。
- 作为一名专业分析用户，我想上传PDF/Excel 分析报告附件，以便分享研报、数据表格，且等待审核后公开展示。

- 作为一名已关注博主的用户，我想接收关注好友动态推送，以便及时获知关注用户的发帖、评论、更新行为。
