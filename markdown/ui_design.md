## 1. 设计规范

### 1.1 色彩系统

| Token | 色值 | 用途 |
|-------|------|------|
| `colorPrimary` | `#1677ff` | 主按钮、链接、激活态 |
| 成功/通过 | `#52c41a` | 审核通过、认证通过 |
| 警告/待处理 | `#faad14` | 待审核、勋章金色 |
| 危险/驳回 | `#ff4d4f` | 驳回、删除、封禁、错误 |
| 背景灰 | `#f5f5f5` | 页面底色 |
| 卡片白 | `#ffffff` | 卡片/面板背景 |
| 边框灰 | `#f0f0f0` | 分割线、卡片边框 |

### 1.2 字体

| 层级 | 字号 | 字重 | 场景 |
|------|------|------|------|
| 页面标题 | 24px | 600 | 页面级 h2 |
| 卡片标题 | 16px | 500 | Ant Design Card title |
| 正文 | 14px | 400 | 帖子正文、评论 |
| 辅助文字 | 12px | 400 | 时间戳、统计数字 |

### 1.3 间距

| Token | 值 | 场景 |
|-------|-----|------|
| `padding` | 24px | 页面内容区 |
| `margin-bottom` | 16px | 卡片间距 |
| `gap` | 12-16px | Flex/Grid 子元素间距 |

### 1.4 组件库

统一使用 **Ant Design 5** 组件，不做二次封装：
- **数据展示**：`Table` `List` `Card` `Tag` `Avatar` `Badge` `Statistic` `Descriptions` `Progress`
- **表单输入**：`Input` `Input.Search` `Input.TextArea`` Select` `Radio` `Checkbox` `Upload` `Tabs`
- **操作反馈**：`Button` `Modal` `message` `Spin` `Empty` `Result`
- **导航**：`Menu` `Dropdown` `Breadcrumb`
- **图标**：`@ant-design/icons`

```

**Header 元素（从左到右）**：
| 元素 | 组件 | 行为 |
|------|------|------|
| Logo "投资论坛" | `<Link>` 文字 | 点击回首页 |
| 搜索框 | `Input.Search` 360px | 回车跳转 `/search?keyword=xxx` |
| 首页图标 | `HomeOutlined` | 跳转 `/dynamics`（动态流） |
| 通知铃铛 | `Badge` + `BellOutlined` | 显示未读数角标，30s 轮询刷新，点击跳转 `/notifications` |
| 私信图标 | `MessageOutlined` | 跳转 `/messages` |
| 群组图标 | `TeamOutlined` | 跳转 `/groups` |
| 发帖按钮 | `Button type="primary"` | 跳转 `/editor` |
| 用户头像 | `Avatar` → `Dropdown` | 下拉菜单：个人主页 / 账号设置 / 我的收藏 / 退出登录 |

**侧边栏（Sider）**：
- 宽度 200px，白色背景
- 动态加载板块树（`GET /sections`）
- 一级菜单为板块名，展开为分区列表
- 点击分区跳转 `/zone/:zoneId`

### 2.3 认证守卫（AuthGuard）

| 场景 | 行为 |
|------|------|
| 未登录访问需登录页面 | 重定向到 `/login`，登录后回到原页面 |
| 已登录但 Token 无用户信息 | 自动调用 `GET /users/me` 获取并存入 store |
| 普通用户访问 `/admin/*` | 重定向到首页 `/` |

**投票交互**：
| 状态 | 表现 |
|------|------|

| 按钮 | 未操作态 | 已操作态 | API |
|------|---------|---------|-----|

| 转发 | `ShareAltOutlined` | toast "链接已复制" | — |

### 5.2 评论列表

**排序**：最新 / 最早 / 最热（`Select` 切换）  
**分页**：每页 20 条

**楼中楼回复交互**：
1. 点击评论的「回复」按钮
2. 评论输入框上方出现 `<Tag closable>回复 @用户A</Tag>`
3. 提交时 `parentCommentId` 指向该评论
4. 关闭 Tag 恢复为直接评论帖子

│                                                 │
│  [选择板块 ▼]  [选择分区（可选）▼]                │  ← Select 联动
│                                                 │
│  ┌─ 投票调研模式 ──────────────────────────┐    │
│  │ 投票标题：___________________________    │    │

│  │ 选项2：_____________________________     │    │
│  │ [+ 添加选项]                             │    │
│  └─────────────────────────────────────────┘    │
│                                                 │
│  ┌─ 普通/长文模式 ────────────────────────┐    │
│  │                                        │    │  ← TextArea
│  │ 输入正文内容...                          │    │  普通: 10行
│  │                                        │    │  长文: 20行
│  │                                        │    │

│                                                 │

│                                                 │

```

**板块-分区联动**：选择板块后，分区 Select 动态加载该板块下的分区列表。

**三种发帖模式差异**：

| 模式 | contentType | 编辑器 | 特色 |

| 普通发帖 | 0 | 10行 TextArea | 支持基础格式 |
| 长文分析 | 2 | 20行 TextArea | 预留富文本升级（react-quill 已引入依赖） |
| 投票调研 | 1 | 投票选项编辑 | 动态增删选项，最低2个 |

## 11. 状态与边界处理

### 11.1 全局状态管理（Zustand）

| Store | 字段 | 说明 |
|-------|------|------|
| `useAuthStore` | `user` / `token` / `isLoggedIn` | 用户登录态，`accessToken` 持久化到 localStorage |
| `useAppStore` | `sections` / `unreadCount` | 板块树（全局缓存）、未读通知数（30s 轮询） |

### 11.2 加载状态

| 场景 | 组件 | 说明 |
|------|------|------|
| 页面级懒加载 | `<Suspense>` + `<Spin size="large" tip="加载中...">` | 首次加载 chunk 时显示 |
| 列表/详情加载 | `<Spin spinning={loading}>` 包裹内容 | 数据请求期间显示旋转器 |
| 表单提交 | `Button loading={submitting}` | 防重复提交 |

### 11.3 空状态

| 页面 | 空状态文案 | 组件 |
|------|-----------|------|
| 首页帖子列表 | "暂无帖子，快来发布第一篇吧" | `<Empty>` |
| 收藏列表 | "还没有收藏任何帖子" | `<Empty>` |
| 私信会话 | "暂无私信会话" | `List locale.emptyText` |
| 群组列表 | "暂未加入任何群组" | `List locale.emptyText` |
| 认证记录 | "暂无认证记录" | `List locale.emptyText` |
| 通知列表 | "暂无通知" | `<Empty>` |
| 用户监控 | "请搜索用户" | `Table locale.emptyText` |

### 11.4 错误处理

| 层级 | 机制 | 表现 |
|------|------|------|
| HTTP 拦截器 | `axios.interceptors.response` | 统一 toast 错误信息 |
| 401 未登录 | 拦截器清除 Token + 重定向 `/login` | 页面跳转 |
| 404 资源不存在 | 页面级判断 | 显示"帖子不存在"/"资源不存在" |
| 表单校验 | Ant Design `Form.Item rules` | 红色提示文字 |

### 11.5 角色权限

| 角色 | 判断条件 | 权限 |
|------|---------|------|
| 游客 | `!isLoggedIn` | 仅可浏览登录/注册页 |
| 普通用户 | `isLoggedIn && isBanned=false` | 浏览、发帖、评论、互动 |
| 管理员 | `verificationLevel >= 3` | 以上全部 + 访问 `/admin/*` |
| 被封禁用户 | `isBanned=true` | 仅可浏览，发帖/评论时提示 |
